# ASSETS

Provenance for every binary art asset in this repo. All 3D models are in `public/models/`. `public/models/manifest.json` is the loader contract: file, heightM, forward, clips by role, bind bbox and notes. Visual design targets are in `docs/visual-targets/` (see `PROMPTS.md` there).

**Rule:** Tripo meshes are set dressing and characters only. They are never colliders, never geography, and never the source of an answer. Terrain, relief and every gameplay fact come from code and data.

## Licence basis

- **Tripo models (new and reused):** generated in the user's own Tripo Studio account, visibility **Private**, on the account's paid credit balance. Use is governed by Tripo's terms of service for that account. No third-party marketplace models, no CC-BY assets, no scraped meshes.
- **Mockups:** generated by ChatGPT image generation in the user's own ChatGPT account. They are design references only and do not ship in the game build.

Text-to-3D in Tripo Studio, model **H3.1**, HD Model, 2K texture, PBR on, Remove Lighting on, Triangle topology, target polycount **20000**, Ultra Mesh off, Private. 30 credits each. The ranger also had **T-Pose** on.

## Processing (all files in `public/models/`)

Raw downloads are kept in `assets-src/tripo/*_raw.glb`, and reused sources in `assets-src/reuse/`.

```sh
# every Tripo raw -> shipped model (no meshopt/draco: plain GLTFLoader)
npx -y @gltf-transform/cli@4 optimize <raw>.glb public/models/<name>.glb \
  --compress false --simplify false --texture-compress webp --texture-size 1024
# reused files that were meshopt/quantized in their old projects
npx -y @gltf-transform/cli@4 dequantize <src>.glb <out>.glb   # then the optimize line above
```

Every shipped file is under 3 MB, Y-up, with its base at y = 0. Tripo normalises the largest extent to 1.0, so scale = `heightM / bindHeight`. The only required extension is `EXT_texture_webp`. `market_stall` also needs `KHR_mesh_quantization`, which three.js supports natively. `fan_palm` needs none.

Extra edits, done with scratch scripts using @gltf-transform/core, jpeg-js and pngjs:

- **minaret:** the base-colour texture came out lavender. Hue 205–295° was shifted to cream limestone (hue 40°), and strong blue (s > 0.55, l < 0.6) was shifted to teal (hue 165°) to match the dome. The result is in `assets-src/tripo/minaret_recolored.glb`, and optimize was then run on it.
- **ranger `run`:** Tripo's retarget baked a +0.40 forward X/Z offset into the `mixamorig:Hips` translation track. Those X/Z keys were set to the bind value, so the clip is truly in place.

**ibex** — Tripo Auto Rig, type "Other" (quadruped), 35 joints with root `tripo::Root` under node `Armature`. Tripo offers only one quadruped preset, `preset:quadruped:walk` (2.58 s). Its AI Animation and Multi-stage Motion are humanoid-only. So **idle, leap, taunt and sulk are procedural** on this skeleton; the recipes and bone names are in `manifest.json`. The third rig/animation job was deliberately not spent, because no quadruped option existed to buy.

Facing: the head looks +Z, but the body is yawed about 33° toward -X. Apply `yawOffsetRad = 0.57` to `rotation.y` so the walk travels along +Z.
